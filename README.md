# Arduino 智能温湿度监测与风扇控制系统

> **课程设计项目**：智能传感网络与检测系统综合设计

这是一个面向课程设计的简单智能传感监测系统，基于 Arduino Uno、DHT22、SSD1306 OLED 和蓝牙串口，实现环境温湿度采集、显示、报警与风扇控制。

项目当前以“能运行、易展示、便于后续整理报告”为目标，后续可在此基础上补充系统框图、流程图、实验数据和 Word 汇报材料。

## 功能

- OLED 显示温度和湿度
- 温度预警与严重报警
- 蜂鸣器和板载 LED 状态提示
- 风扇自动、强制开启和强制关闭模式
- 按键切换 OLED 页面
- 通过蓝牙串口查询状态和控制风扇
- 通过蓝牙校时，按上午、下午和夜间自动切换温度阈值
- 通过蓝牙修改分时温度阈值和全天湿度阈值
- 提供 VOFA+ FireWater 串口输出测试程序

## 硬件连接

| 模块 | Arduino Uno |
| --- | --- |
| DHT22 DATA | D2 |
| 蜂鸣器 | D3 |
| 页面按键 | D4（使用内部上拉） |
| 风扇控制 | D9 |
| OLED SDA | A4 |
| OLED SCL | A5 |
| OLED 地址 | `0x3C` |

蓝牙模块使用 Arduino Uno 的硬件串口，波特率为 `9600`。风扇驱动应使用合适的晶体管或继电器模块，不要直接由 Arduino 引脚带动大功率负载。

## 软件依赖

在 Arduino IDE 的库管理器中安装：

- Adafruit GFX Library
- Adafruit SSD1306
- DHT sensor library

## 使用方式

1. 在 Arduino IDE 中打开 `UNO_DHT22_OLED/UNO_DHT22_OLED.ino`。
2. 安装所需库并选择 Arduino Uno 开发板。
3. 按照上表完成接线。
4. 编译并上传程序。
5. 通过按键切换 OLED 页面，或通过蓝牙发送以下命令：

```text
STATUS
HELP
TIME 08:00
SET DAY 25 30
SET PM 23 28
SET NIGHT 12 15
SET HUM 70 80
PAGE 0
PAGE 1
PAGE 2
FAN AUTO
FAN ON
FAN OFF
ALARM OFF
ALARM ON
OK
```

`ALARM OFF` 仅停止蜂鸣器声音，OLED、LED 和风扇安全控制仍然有效；发送 `ALARM ON` 可重新打开声音。发送 `OK` 也可以静音蜂鸣器。Arduino 复位后报警声音默认打开；温度或湿度达到报警阈值时蜂鸣器才会响。

未校时时温度达到 `28 °C` 进入预警、达到 `30 °C` 进入严重报警；校时后使用下表中的分时温度阈值。湿度达到 `70%RH` 时进入预警、达到 `80%RH` 时进入严重报警。温度回差为 `1 °C`，湿度回差为 `5%RH`。OLED 和 `STATUS` 会显示报警来源：`TEMP`、`HUM` 或 `TEMP+HUM`。

## 草莓大棚分时阈值

`TIME 08:00` 只是示例，支持 `00:00`～`23:59:59` 的任意当地时间，格式为 `TIME HH:MM[:SS]`。校时后程序使用 `millis()` 的无符号时间差推进软件时钟，并根据时间自动选择阈值：

| 时段 | 当地时间 | 温度预警/严重 | 湿度预警/严重 |
| --- | --- | --- | --- |
| DAY 上午 | 06:00～11:59:59 | 25/30 ℃ | 70/80 %RH |
| PM 下午 | 12:00～17:59:59 | 23/28 ℃ | 70/80 %RH |
| NIGHT 夜间 | 18:00～次日 05:59:59 | 12/15 ℃ | 70/80 %RH |
| UNSET 未校时 | 启动或复位后 | 28/30 ℃ | 70/80 %RH |

上午阈值高于下午是课程原型的通风管理策略：夜间后先允许棚温回升，下午考虑日照和棚体蓄热而提前通风。地方标准只给出白天和夜间参考范围，并未规定上午必须高于下午，实际应用需要结合品种、生育期、季节和棚内实测数据调整。

温度与相对湿度在水汽含量基本不变时常呈反向变化，但棚内蒸腾、灌溉、通风和结露都会改变水汽含量，因此程序分别测量和判断温度与湿度，不能用温度直接推算相对湿度。

`SET DAY/PM/NIGHT W C` 修改对应时段的温度预警值和严重值；`SET HUM W C` 修改全天湿度阈值。温度预警值不得低于 5 ℃、严重值不得高于 45 ℃且两者至少相差 1 ℃；湿度预警值不得低于 30%RH、严重值不得高于 100%RH且两者至少相差 5%RH。设置会立即用于显示和报警判断，复位后恢复默认值。

软件时钟没有断电保持能力，复位或断电后需要重新发送 `TIME`。`millis()` 的 32 位毫秒计数约 49.7 天回绕一次，程序使用增量和无符号时间差继续计时；长期运行仍应定期校准，后续可增加 DS3231 实时时钟模块。
